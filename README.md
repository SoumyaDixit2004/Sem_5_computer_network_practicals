# Computer Networking Laboratory

This project focuses on the study and implementation of key concepts in **Computer Networking**. It begins with the study of the **basic elements of networking**, explaining the role of devices such as routers, switches, hubs, bridges, repeaters, and gateways that form the foundation of communication networks. Using **Cisco Packet Tracer**, packet analysis is performed to observe and analyze **Application Layer packets** like HTTP, DNS, and FTP, helping to understand data flow across network layers.

Further, **Socket Programming** is implemented to demonstrate communication at the **Transport Layer** using both **TCP** (reliable, connection-oriented) and **UDP** (fast, connectionless) protocols. The **Sliding Window Protocols** such as **Go-Back-N** and **Selective Repeat** are implemented to ensure reliable data transmission through acknowledgment and retransmission mechanisms.

The project also includes **Traffic Shaping Algorithms** like the **Leaky Bucket** and **Token Bucket**, which control data flow and prevent congestion by regulating packet transmission rates. Finally, the **Distance Vector Algorithm** is implemented to demonstrate dynamic routing, where routers exchange information to determine the shortest path using the **Bellman-Ford algorithm**.

Overall, this project provides a practical understanding of how data is transmitted, controlled, and routed efficiently across computer networks.
